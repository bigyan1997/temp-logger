## Orders PC checklist (after pulling)
Full detail is in docs/DEPLOYMENT.md. In short:
1. **Already set up** (a `backend\.env` exists, database and logins made): `git pull`, then `.\scripts\deploy.ps1`. It installs packages, runs tests, builds the frontend, migrates (picks up settings 0008/0009, readings 0004/0005, alerts) and restarts the server.
2. **First time**: follow "First-time setup" steps 1 to 9 in docs/DEPLOYMENT.md (clone, Postgres role and database, venv, `.env`, `migrate`, `create_default_logins`, `npm run build`, firewall rule for port 8003, `install_autostart.ps1` as administrator).
3. Run `install_autostart.ps1` again as administrator (safe to repeat) so the 5-minute "Temperature Logger Alerts" task exists.
4. Nightly backup (step 10): set `BACKUP_DIR` (local `backups` folder) and `BACKUP_DRIVE_DIR` (`G:\My Drive\Temp Logger Backups`) in `backend\.env`; the task has no `-BackupDir`, runs as the Drive user and has "run as soon as possible after a missed start" on. Run `scripts\backup.ps1` once and check `backup.log` shows both the local file and the Drive copy. **Done on the orders PC 2026-11-11.**
5. Alert emails (step 11): put `EMAIL_*` in `backend\.env`, add an address under Settings, Alert emails, then `python manage.py send_alerts --demo`. Reminders go at 30 minutes before and 3 hours after each reading (8:30 am/12 pm, 8:30 pm/12 am, Fri 2:30 pm/6 pm).
6. Reports to Google Drive (step 12): `REPORTS_EXPORT_DIR=G:\My Drive\Temp Logger Reports` and `install_report_export.ps1`. **Done on the orders PC 2026-11-11**; the first 4-week PDFs are due 29 Nov 2026, so check that folder (and `export_reports.log`) then.
7. Open `http://localhost:8003`, log in as both accounts, log a test reading and void it, then confirm another PC on the LAN and Tailscale can reach it. Restart the PC once to confirm it comes back by itself.
8. New in 2026-11: the Calibration module and the all-records page. `migrate` picks up `calibration` 0001/0002 and `audit` 0006. Log in as the day login and check the front page shows Temperature Logger, Calibration and Records cards, then open Records and click each tab. Calibration PDF copies go to `report_exports/calibration/` plus the Drive folder if `GOOGLE_DRIVE_FOLDER_ID` is set; the calibration due emails use the same alert addresses as the reminders.
9. Do not run a plain `npx vite build` on the live folder. Keep real hostnames, IPs and passwords in the gitignored `DEPLOYMENT_NOTES.md`.
